# Essamsportball — starter project

This is a **source starter**, not a built PS4 PKG.

## What is included
- `prototype/index.html`: phone-browser prototype of the Arabic controller-friendly UI.
- `data/channels.json`: sample channel-list format. It intentionally contains no invented stream URLs.
- `native/src/main.cpp`: minimal SDL2 UI shell for a future OpenOrbis-based PS4 port.
- `BUILD-NOTES.md`: practical Android-only workflow and known limitations.

## Current scope
The prototype demonstrates layout and navigation. It does not play video and is not directly installable on PS4.
Only add stream URLs published by the channel/operator or another clearly authorized source.
